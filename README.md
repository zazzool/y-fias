# Y-FIAS

Адресный сервис МИС «Вызов»: поиск, распознавание, исправление и подстановка
адресов. Отдельное серверное приложение на Go, заменяющее адресную подсистему,
описанную в [`address-subsystem-inventory.md`](address-subsystem-inventory.md).

## Суть решения в трёх пунктах

1. **Справочник Москвы и МО целиком в памяти процесса (~300 МБ).** Отсюда
   отсутствие сети и SQL на горячем пути, отклик подсказки p99 ≤ 5 мс и
   работоспособность при недоступности интернета и PostgreSQL.
2. **Тождество адреса — по полному разобранному номеру дома**, не по ведущему
   числу. 6036 из 10 694 адресов содержат кириллицу в номере; «дом = число» —
   неверная модель, и именно она уже приводила к подмене введённого номера.
3. **Замкнутый цикл обучения на собственных данных** — 92 000 вызовов,
   подтверждённые человеком исправления, история пациента. Это то, чего у
   универсальных адресных сервисов нет и не будет.

## Инварианты

Не обсуждаются, проверяются тестами (подробно — §0 архитектуры):

1. Ввод пользователя неприкосновенен: сервис предлагает, но не подменяет.
2. Тождество — по полной канонической форме дома; число дома — только предфильтр.
3. Организация — рядом с адресом, никогда вместо него.
4. ПНД устанавливает человек.
5. Одно правило нормализации — один код (SQL генерируется из Go).
6. Квартира, подъезд, этаж, домофон — свойства вызова, не адреса.
7. `organization` (что по адресу вызова) ≠ место эвакуации.
